# AGENTS.md

## Sobre o projeto

**clone-tabnews-ia** é uma reimplementação do [TabNews](https://tabnews.com.br) desenvolvida para o [curso.dev](https://curso.dev), construída com o auxílio de agentes de IA.

Repositório: https://github.com/fabiosvf/clone-tabnews-ia

## Stack

- **Next.js** com **App Router** (diretório `app/`)
- **React** / **React DOM**
- **JavaScript** puro (sem TypeScript)

## Comandos

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm start` — servir o build de produção
